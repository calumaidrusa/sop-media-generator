# sop-media-generator

本機使用的 AI 內部 SOP 多媒體快速生成器。使用者提供文字、公開網址、操作截圖與螢幕錄影，系統整理成 5～10 個可編輯步驟，再套用模板輸出成教學講義、漫畫對話、社群圖卡與旁白字幕影片。

## 快速預覽

雙擊 `開啟SOPStudio.cmd` 即可啟動本機網站。有聲影片的語音轉文字需要透過本機伺服器執行；直接開啟 `index.html` 仍可使用畫面擷取與步驟編輯。示範案例為「如何查詢自己的准考證號碼」。第一次按下「轉錄影片聲音」時會下載 Whisper base 模型。

## 目前已完成

- 三種素材入口：截圖、公開網址、螢幕錄影。
- 步驟標題與說明編輯、拖曳排序、新增步驟。
- 簡潔講義、漫畫對話、社群圖卡三種預覽模板。
- PDF 列印預覽入口與影片／圖卡輸出提示。
- 影片上傳後在瀏覽器本機擷取 1～3 張代表畫面。
- 本機 Whisper 語音轉文字，保留逐字稿時間點。
- 使用 localStorage 自動暫存步驟、順序、主題與模板，重新開啟會恢復草稿。
- 可按右上角「儲存草稿」立即保存目前內容；請固定使用同一個 `http://127.0.0.1:4173` 入口，避免 `file://` 與本機伺服器各自產生不同暫存區。
- 可用右上角 `JSON` 匯出完整專案、`MD` 匯出可閱讀文字，並用「載入」重新匯入 JSON；步驟數量不限於 5～10。
- 可用右上角 `ZIP` 一次打包 JSON、Markdown 與所有擷取畫面。
