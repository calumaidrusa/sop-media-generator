# Decisions

| 日期 | 決策 | 原因 |
| --- | --- | --- |
| 2026-08-21 | 依 CalumAi 規格初始化專案 | 讓不同 AI 可以直接接手 |
| 2026-08-21 | 第一版定位為本機使用的內部 SOP 多媒體快速生成器 | 先驗證生成與編輯體驗，再考慮正式部署 |
| 2026-08-21 | 輸入採混合模式，輸出包含 PDF、影片、漫畫說明與圖卡說明 | 使用者希望同一份 SOP 可轉成不同教學媒介 |
| 2026-08-21 | AI 預設拆解為 5～10 個步驟 | 符合參考操作講義的閱讀節奏 |
| 2026-08-21 | 真實截圖與螢幕錄影是主要素材，AI 生成素材只作為主題周邊補充 | 確保企業 SOP 的畫面與實際系統一致 |
| 2026-08-21 | 網址不預期需要登入 | 第一版先處理公開頁面或使用者已提供的素材 |
| 2026-08-21 | 教學影片需要旁白與字幕 | 輸出要能直接作為教學內容使用 |
| 2026-08-21 | 第一個驗證案例是查詢自己的准考證號碼 | 具體且適合測試多步驟教學輸出 |

## 待確認假設

- 第一版是否需要真的串接 AI API，或先用可替換的模擬生成器驗證介面。
- 網址與螢幕錄影的解析範圍、支援格式與本機權限仍待確認。
- 各輸出格式的優先順序與最低可驗收品質仍待確認。
